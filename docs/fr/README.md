# Parcours français — base

## Intention
Base coordonne l’exécution et le consensus d’une L2 OP Stack : le nœud orchestre l’état, les pairs, le séquenceur et les outils opérateur.

## Architecture
Identifier les modules de contrôle, les interfaces publiques, la configuration et les dépendances externes.

## Déroulement
Décrire l’entrée, les validations, les changements d’état et la sortie observable.

## Sécurité
Examiner permissions, signatures, domaines de confiance, rejouabilité et gestion des erreurs.

## Intégration Base
Relier le composant aux RPC, contrats précompilés, réseau L2 ou outils de développement concernés.

## Lecture guidée
Commencer par README, poursuivre par les fichiers centraux, scripts et tests.

## Exploitation
Conserver versions, paramètres, journaux et métriques afin de rendre les résultats comparables.

## Glossaire
Termes propres au dépôt expliqués en français et reliés à leur usage dans Base.
